Served outside the map

These path prefixes are listed in build.js, not in the gloomap. Any request under them is passed to dynamic.php, which proxies the same path on HubSpot. This is how the News listing, its tag pages, and individual posts load.

    Reading a row. The grey path is what the build generates from the labels. It is a real page only when the row has a green HubSpot chip; struck through, it is what the path would be once a URL is added. no URL means the gloomap box has no #https://… line, so the menu shows a red unlinked label. menu → means the same thing, except a hard-coded override in shell-renderer.js makes the menu link somewhere anyway. not in menu means the box is deeper than the two levels the site menu renders. An orange chip means the page is proxied from another CESMII host that proxy.php allows. A red chip means the host is not allowed and the page would show an error.
